# Data Availability

## Publicly released

This repository releases only materials that can be redistributed without exposing restricted study text:

- analysis and verification code;
- frozen computational protocol information;
- aggregate statistics and result tables;
- OOF prediction files containing identifiers, folds, target labels, predictions, probabilities, and human-easy/hard flags where already part of the computational evaluation outputs;
- SHA-256 hashes of frozen restricted input workbooks.

## Restricted

The following are **not** included in this public repository:

- prompt text;
- authorised source/context text;
- generated model response text;
- original A1/A2/A3 annotation workbooks;
- senior-adjudication and targeted re-review records;
- the full FINAL GOLD workbook;
- any other row-level material whose redistribution is constrained by institutional or model-output terms.

The manuscript therefore does not claim unrestricted public release of the full case-level corpus. Reproducibility is supported through public code, exact hashes, frozen folds/seeds/model revisions, public OOF predictions where permissible, and aggregate diagnostics.
